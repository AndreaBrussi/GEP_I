# GEP I Project (formerly NAGE Inventory I)

A set of standalone Python tools dedicated to the numerical evaluation and modeling of average photon escape distances and trajectories within thin galactic disks and elliptical stellar systems.

Manuscript Reference: [Zenodo DOI](https://doi.org/10.5281/zenodo.22009753)

Website Reference: [andreabrussi.it](https://andreabrussi.it)  
Contact: info@andreabrussi.it  - [ORCID](https://orcid.org/0009-0000-3924-1563)

---

## Zip Content

The package includes the following computation and visualization scripts:

*   Brussi_2026_GEP_I_disk_escape_trajectory_file1.py – Numerical evaluation of Freeman-profile-weighted average photon escape distances from a thin disk, scanning custom $R/h$ ratios.
*   Brussi_2026_GEP_I_elliptic_escape_trajectory_file2.py – Modeling and geometric analysis of isotropic mean escape path lengths across oblate and prolate elliptical morphologies, featuring automated plotting.

---

## Usage and Data Entry

All scripts are standalone applications designed to be executed directly from the terminal (command-line interface).

1. Open your terminal in the directory where you extracted the ZIP archive.
2. Run the desired script using Python (e.g., python Brussi_2026_GEP_I_disk_escape_trajectory_file1.py).
3. View the generated tabular outputs directly in the terminal, or interact with the pop-up graphical visualization generated by the plotting script.

---

## Dependencies and Requirements

To run these scripts, your Python environment must include the following scientific libraries:

*   NumPy – For matrix operations and array processing.
*   SciPy – Specifically scipy.integrate (for quad and dblquad numerical integration) and scipy.special (for elliptic integrals ellipe).
*   Matplotlib – Required by file2.py to render the behavioral trajectory graphs.
